# ALIVE Meeting Records

This folder contains the official meeting notes for the ALIVE project.

## Required cadence

- Team-only meeting: at least once every week
- Advisor meeting: at least once every two weeks

## File names

Create one Markdown file per meeting:

- `YYYY-MM-DD-team.md`
- `YYYY-MM-DD-advisor.md`

If two meetings of the same type occur on the same date, add a short distinguishing suffix, such as `YYYY-MM-DD-team-planning.md`.

## Required content

Every note must identify:

- Meeting type, date, time, mode, and attendees
- Work completed since the previous meeting
- Work completed and decisions made during the meeting
- Issues and blockers
- Action items, with one owner and a due date for each item
- Goals for the next meeting

Use [`_template.md`](_template.md) to create each record. Replace every placeholder and remove unused blank bullets before committing the note.

## Submission

For each meeting-log assignment, submit the direct GitHub link to this folder in the Canvas text-entry box. The notes themselves remain in GitHub.
